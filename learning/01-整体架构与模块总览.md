## 二、核心模块一览表

### 2.1 共识/验证层（最核心）

| 模块 | 路径 | 职责 |
|------|------|------|
| **区块/交易验证** | `src/validation.cpp` (324KB) | `ConnectBlock()`、`CheckBlock()`、IBD 驱动 |
| **共识规则** | `src/consensus/` | 无外部依赖的纯规则：merkle、tx_check、params |
| **Script 解释器** | `src/script/interpreter.cpp` | 栈机虚拟机，OP_* 全部实现 |
| **UTXO 视图** | `src/coins.cpp` | `CCoinsView` 抽象层，缓存写时复制 |
| **PoW** | `src/pow.cpp` | 难度目标计算、nBits 转换 |
| **Merkle** | `src/consensus/merkle.cpp` | 交易根哈希计算 |
| **软分叉状态** | `src/versionbits.cpp` | BIP9 状态机 |
| **Kernel 库** | `src/kernel/` | 可提取的共识代码，面向 libbitcoinkernel |

**关键数据流：收到新区块**
```
net_processing.cpp::ProcessNewBlock()
  → validation.cpp::ChainstateManager::ProcessNewBlock()
    → CheckBlock()          // 格式检查
    → AcceptBlock()         // 加入 block index
    → ActivateBestChain()   // 尝试将最重链设为主链
      → ConnectBlock()      // UTXO 状态转换 + 脚本验证
        → script/interpreter.cpp  // 每个输入的 Script 验证
```

### 2.2 存储层

| 模块 | 路径 | 职责 |
|------|------|------|
| **块存储** | `src/node/blockstorage.cpp` | blk*.dat / rev*.dat 文件管理 |
| **UTXO DB** | `src/txdb.cpp` | LevelDB 上的 chainstate 表 |
| **块索引 DB** | `src/txdb.cpp` | LevelDB 上的 blocks/index 表 |
| **LevelDB 封装** | `src/dbwrapper.cpp` | `CDBWrapper`、`CDBIterator` |
| **平坦文件** | `src/flatfile.cpp` | `FlatFilePos` 定位 blk*.dat |

**磁盘数据目录结构**
```
~/.bitcoin/
  blocks/
    blk00000.dat     ← 原始区块数据（魔数+长度+块）
    blk00001.dat
    rev00000.dat     ← undo 数据（支持回滚）
    index/           ← LevelDB：block index (CBlockIndex)
  chainstate/        ← LevelDB：UTXO set (CCoins)
  wallets/
  peers.dat          ← AddrMan 序列化
  mempool.dat        ← mempool 持久化
```

### 2.4 P2P 网络层

| 模块 | 路径 | 职责 |
|------|------|------|
| **连接管理** | `src/net.cpp` (157KB) | `CConnman`：Socket I/O、出入站连接、流量控制 |
| **消息处理** | `src/net_processing.cpp` (284KB) | `PeerManager`：所有消息类型的业务逻辑 |
| **地址管理** | `src/addrman.cpp` | 二级 bucket 结构，防 Sybil |
| **P2P 协议** | `src/protocol.cpp` | 消息类型常量（MSG_TX/MSG_BLOCK 等） |
| **紧凑块** | `src/blockencodings.cpp` | BIP152：只传差量 |
| **BIP324** | `src/bip324.cpp` | v2 加密传输 |
| **Headers 同步** | `src/headerssync.cpp` | 防低难度链 DoS |
| **交易请求** | `src/txrequest.cpp` | 多 peer 去重请求调度 |
| **Erlay** | `src/node/txreconciliation.cpp` | 集合协调降低带宽 |
| **Tor/I2P** | `src/torcontrol.cpp`, `src/i2p.cpp` | 匿名网络支持 |

**P2P 消息处理流程（以收到 inv 为例）**
```
CConnman::ThreadMessageHandler()
  → PeerManager::ProcessMessages()
    → PeerManager::ProcessMessage()   // 根据 msg.type 分发
      case "inv": ProcessInv()
        → 过滤已知 / 记录 txrequest
      case "tx": ProcessTransaction()
        → AcceptToMemoryPool()
      case "block": ProcessBlock()
        → ProcessNewBlock()
```

## 四、三条主线理解整个系统

### 主线一：一笔交易从创建到确认

```
[用户钱包]
  CWallet::CreateTransaction()           // src/wallet/spend.cpp
    → CoinSelection::SelectCoins()       // src/wallet/coinselection.cpp
    → 签名 (secp256k1 ECDSA/Schnorr)
    
[广播]
  CWallet::CommitTransaction()
    → CConnman::RelayTransaction()       // src/net.cpp
    → 发送 inv 消息给 peers

[对端接收]
  PeerManager::ProcessMessage("tx")      // src/net_processing.cpp
    → AcceptToMemoryPool()               // src/txmempool.cpp
      → CheckTransaction()              // src/consensus/tx_check.cpp
      → PolicyScriptChecks()            // script 验证
      → CTxMemPool::addUnchecked()      // 加入内存池
      
[矿工打包]
  BlockAssembler::CreateNewBlock()       // src/node/miner.cpp
    → 按费率排序选交易
    
[区块上链]
  ConnectBlock()                         // src/validation.cpp
    → ApplyTxInUndo() / UpdateCoins()   // UTXO 状态更新
    → 交易从 mempool 移除
```

### 主线二：节点冷启动 IBD

```
AppInitMain()                            // src/init.cpp
  → 加载 chain params
  → 打开 LevelDB (chainstate + block index)
  → 启动 CConnman (P2P 连接)
  → 发送 getheaders 给 peers
  
IBD 流程:
  getblocks → inv → getdata → block
  ValidateBlock() + ConnectBlock()       // 追链
  直到 nChainWork 达到 checkpoints
```

### 主线三：软分叉激活

```
versionbits.cpp::VersionBitsState()
  DEFINED → STARTED → LOCKED_IN → ACTIVE → FAILED
  基于 2016块统计信号位，BIP9 状态机
```

## 五、关键设计模式

### CCoinsView 分层缓存
```
CCoinsViewDB (LevelDB)          ← 磁盘
  └── CCoinsViewCache            ← 内存，脏标记
        └── CCoinsViewCache      ← 连接块时的临时视图
```

### 接口隔离（multiprocess 准备）
```
src/interfaces/chain.h          ← 钱包访问链的抽象接口
src/interfaces/wallet.h         ← 节点访问钱包的抽象接口
src/interfaces/node.h           ← GUI 访问节点的抽象接口
→ 允许进程间 IPC (src/ipc/capnp/)
```

### 并行脚本验证
```
src/checkqueue.h                ← CCheckQueue<T>
  多线程消费脚本验证任务
  主线程只在最后 Wait() 汇总结果
```

## 六、学习建议

1. **从 `primitives/` 开始**，先搞清楚 `CTransaction`、`CBlock` 的序列化格式
2. **然后看 `script/interpreter.cpp`**，用测试用例跑通几个 P2PK / P2PKH / P2WPKH 脚本
3. **再看 `validation.cpp::ConnectBlock()`**，这是整个系统最核心的函数
4. **P2P 先看协议消息**（`src/protocol.h`），再看 `net_processing.cpp` 按消息类型阅读
5. **不要上来就看 `init.cpp`**，它是"胶水"代码，看完核心模块再来串联
