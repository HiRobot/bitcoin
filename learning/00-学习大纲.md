# Bitcoin Core 源码学习大纲

> 面向：有扎实 C/Java 开发基础，首次深入区块链底层的工程师
> 目标：从整体架构到核心模块，逐步掌握 Bitcoin Core 的设计原理与实现细节

---

## 学习路径概览

```
阶段一：基础数据结构与编码（1-2周）
  └── 理解 Bitcoin 的基本数据单元：交易、区块、脚本、地址

阶段二：密码学基础（1周）
  └── 哈希函数、签名、密钥派生，比特币所有安全性的根基

阶段三：共识层（2-3周）
  └── 最重要的部分：Script 虚拟机、UTXO 模型、区块验证规则

阶段四：存储层（1周）
  └── LevelDB、区块文件、UTXO 集的落盘与查询

阶段五：内存池（1-2周）
  └── mempool 的结构、替换规则、集群线性化算法

阶段六：P2P 网络（2周）
  └── 节点发现、连接管理、消息协议、交易/区块传播

阶段七：初始化与同步（1-2周）
  └── IBD 流程、节点启动、假设UTXO快照

阶段八：钱包（1-2周）
  └── 密钥管理、UTXO 选择、交易构建、PSBT

阶段九：RPC/REST/ZMQ（0.5周）
  └── 对外接口设计

阶段十：进阶专题（按兴趣）
  └── BIP324加密传输、Taproot/Miniscript、Erlay、多进程架构
```

## 阅读源码的基本姿势

### 数据流视角
任何时候都可以从这两条主线切入：
1. **一笔交易的一生**：从用户发起 → mempool → 打包进区块 → 上链
2. **一个区块的验证**：收到区块 → headers 检查 → 下载完整块 → 脚本验证 → 更新 UTXO

### 关键全局对象
```cpp
// 理解这几个对象之间的关系，等于理解了节点的核心
ChainstateManager  // 链状态总管，在 src/validation.h
CTxMemPool         // 内存池，在 src/txmempool.h
CConnman           // 连接管理，在 src/net.h
PeerManager        // P2P 消息处理，在 src/net_processing.h
BlockManager       // 块文件管理，在 src/node/blockstorage.h
```

### 重要的锁
```cpp
cs_main     // 链状态大锁，持有时不能持 cs_wallet
cs_wallet   // 钱包锁
m_mutex     // mempool 锁
```

### 调试建议
- 从 `src/init.cpp` 的 `AppInitMain()` 开始，追踪各模块初始化顺序
- 用 GDB 在 `validation.cpp::ConnectBlock()` 打断点观察区块上链
- 用 `bitcoin-cli` 触发 RPC 对应到 `src/rpc/` 的具体实现
